================================================================================
 题5 简易数字示波器 (ADC + DMA + FSMC LCD) —— 参考实现 (纯文本, 不参与编译)
 适用: 正点原子 STM32F103ZET6 + 你 42_LCD_HAL 的自写 LCD 驱动 + CubeMX HAL 工程
 交付形式: osc.h / osc.c 两个文件, 手敲或对照抄进自己的新工程
================================================================================

一、总体数据流 (先想清楚再动手)
--------------------------------------------------------------------------------
TIM3 (72MHz / 3600 = 20kHz, 每次溢出发一次 TRGO)
  |  硬件触发, 不占 CPU —— "采样率由定时器触发, 不准 ADC 自由运行"就靠这个
  v
ADC1 (PC0 = ADC1_IN10, 每来一个 TRGO 只转一个数)
  |  DMA1_Channel1 循环(Circular)搬运, 全程无 CPU 参与
  v
adc_buf[2048] 环形缓冲 —— 等效一卷磁带: 2048 / 20kHz = 102ms 历史
  |  每帧: 停 TIM3 -> 顺序拷最近 N 个样本到 trace[] -> 重启 TIM3 (防撕裂)
  v
trace[] 一帧快照 (1ms/格 取 200 个, 10ms/格 取 2000 个)
  |  ① 软件触发: 找第一个"上升穿中点"的样本, 每帧从同一相位画 => 稳定不滚动
  |  ② 测量: 峰峰值 / 过中点测周期算频率 / 占空比 (全程整数运算)
  v
LCD 240x320 竖屏: 顶部状态栏, 中间 200x160 网格画波形, 底部测量栏

帧率约 20FPS, 主循环裸跑即可, 不需要 RTOS。


二、CubeMX 配置清单 (建议直接复制 42_LCD_HAL.ioc 改名, FSMC/USART/LCD 全保留)
--------------------------------------------------------------------------------
1. Clock Configuration —— 42 工程现在是 8MHz 降速实验状态, 本工程必须恢复 72MHz:
   HSE = Crystal/Ceramic Resonator, PLL Source = HSE, PLLMul = x9 => SYSCLK 72MHz
   AHB /1, APB1 /2 (36MHz), APB2 /1 (72MHz)
   ADC 预分频 (Clock 页的 ADCCLK): PCLK2/6 = 12MHz  (F1 的 ADC 时钟上限 14MHz)

2. ADC1:
   - Enabled Regular Channels: IN10 (PC0)
   - Scan Conversion Mode:        Disabled
   - Continuous Conversion Mode:  Disabled   <-- 关键! 开了 = 自由运行, 题目禁止
   - External Trigger Conversion Source: Timer 3 Trigger Out event (T3_TRGO)
   - Data Alignment: Right
   - Number Of Conversion: 1
   - Sampling Time: 28.5 Cycles   (28.5+12.5=41 周期 @12MHz ≈ 3.4us << 50us)

3. DMA Settings (在 ADC1 配置页里): Add -> ADC1
   - Mode: Circular                          <-- 关键! 磁带一直转
   - Data Width (Peripheral/Memory): Half Word / Half Word

4. TIM3 (Mode: Clock Source = Internal Clock):
   - Prescaler: 0
   - Counter Period: 3599                    (72MHz/3600 = 20kHz, 对应 OSC_FS)
   - Trigger Event Selection (TRGO): Update Event   <-- 关键!

5. TIM1 (可选, 板载自测信号): Channel1 = PWM Generation CH1
   - Prescaler 71, Counter Period 999, Pulse 500  => PA8 输出 1kHz / 50%
   (若用参考代码里的 OSC_TestSignal_Start(), 这一步整段跳过, 二选一)

6. GPIO: PE4 / PE3 = Input Pull-up, PA0 = Input Pull-down
   (osc.c 的 keys_init() 会自己配一遍, 这里配不配都行)

7. NVIC: 一个中断都不用开。DMA 循环 + 轮询读缓冲, 不需要中断。

8. 生成代码后检查 main.c 顺序: MX_DMA_Init() 必须排在 MX_ADC1_Init() 之前。
   CubeMX 一般自动排对, 但重新生成时偶尔乱序, 乱序则 DMA 一个数都收不到。

9. Keil: 把 osc.c 加入工程 (同 lcd.c 的加法)。stm32f1xx_it.c 不用动。


三、硬件接线
--------------------------------------------------------------------------------
- ADC 输入: PC0 (ADC1_IN10) —— 你 33 号工程验证过的引脚, 排针杜邦线引出
- 板载自测信号: PA8 (TIM1_CH1) --杜邦线--> PC0, 得到 1kHz / 50% 方波,
  不用信号发生器就能完成方波验收
- 正弦波: 需要信号发生器, 设为 1kHz、直流偏置 1.65V、幅度 <= 3.3Vpp
- !! 警告: ADC 引脚耐压 0 ~ 3.3V (绝对上限 VDDA+0.3V)。信号发生器若是 ±5V
  双极性输出, 直接接会打坏引脚, 必须先电阻衰减/加直流偏置。
- 按键: KEY0=PE4, KEY1=PE3, KEY_UP=PA0 (板载自带)


四、代码: osc.h  (新建到 Core/Inc)
--------------------------------------------------------------------------------
#ifndef __OSC_H
#define __OSC_H

#include "main.h"

/* ---- 采样 ---- */
#define OSC_BUF_LEN     2048u         /* DMA 环形缓冲: 2048 @ 20kHz = 102ms 磁带 */
#define OSC_FS          20000u        /* 采样率 Hz。改这里必须同步改 TIM3 分频 */

/* ---- 波形窗口: 240x320 竖屏, 上 32px 状态栏, 下留测量栏 ---- */
#define OSC_X0          20
#define OSC_Y0          32
#define OSC_W           200u          /* 10 格 x 20px */
#define OSC_H           160u          /* 8 格 x 20px */
#define OSC_PX_PER_DIV  20

/* ---- 颜色 (RGB565) ---- */
#define OSC_C_BG     0x0000           /* 黑 */
#define OSC_C_GRID   0x2104           /* 暗灰 */
#define OSC_C_GRIDC  0x39E7           /* 中十字/边框: 暗青 */
#define OSC_C_TRACE  0xFFE0           /* 黄 */

typedef enum { OSC_TB_1MS = 0, OSC_TB_10MS } osc_tb_t;
typedef enum { OSC_VDIV_1V = 0, OSC_VDIV_500MV, OSC_VDIV_250MV } osc_vdiv_t;

void OSC_Init(void);             /* 按键 + ADC 校准 + DMA + TIM3 启动 */
void OSC_UIInit(void);           /* 画网格 + 静态文字 (LCD 初始化之后调) */
void OSC_Task(void);             /* 主循环反复调: 扫按键 + 按 50ms 节拍出帧 */
void OSC_TestSignal_Start(void); /* 可选: PA8 输出 1kHz/50% 方波当验收信号 */

#endif


五、代码: osc.c  (新建到 Core/Src)
--------------------------------------------------------------------------------
#include "osc.h"
#include "adc.h"        /* CubeMX 生成的 hadc1 */
#include "tim.h"        /* CubeMX 生成的 htim3 */
#include "lcd.h"
#include <stdio.h>

/* ==================== DMA 环形缓冲 (一卷 102ms 的磁带) ==================== */
static uint16_t adc_buf[OSC_BUF_LEN];

/* ==================== 一帧快照 ==================== */
#define TRACE_MAX  2000u                  /* 10ms/格: 100ms x 20kHz */
static uint16_t trace[TRACE_MAX];
static uint16_t trace_n = 200u;           /* 本帧样本数: 1ms/格=200, 10ms/格=2000 */

/* ==================== 状态 ==================== */
static osc_tb_t   s_tb      = OSC_TB_1MS;
static osc_vdiv_t s_vdiv    = OSC_VDIV_1V;
static uint8_t    s_trig_en = 1u;
static uint32_t   s_last_ms = 0;
#define FRAME_MS 50u                          /* ~20 FPS */

/* ==================== 测量结果 ==================== */
typedef struct {
    uint16_t code_max, code_min;
    uint32_t vpp_mv;                          /* 峰峰值, mV */
    uint32_t freq_x10;                        /* 频率 x10 Hz, 0 = 测不到 */
    uint32_t duty_x10;                        /* 占空比 x10 %, 0xFFFFFFFF = 测不到 */
} meas_t;

/* ---------- LCD 小工具: 你的 LCD_SetArea 末尾已发 0x2C, 连写数据即填充 ---------- */
static void fill_rect(uint16_t x, uint16_t y, uint16_t w, uint16_t h, uint16_t color)
{
    LCD_SetArea(x, y, w, h);
    uint32_t total = (uint32_t)w * h;
    while (total--) LCD_WriteData(color);
}

static void draw_grid(void)
{
    uint16_t x1 = OSC_X0, y1 = OSC_Y0;
    uint16_t x2 = OSC_X0 + OSC_W - 1u, y2 = OSC_Y0 + OSC_H - 1u;

    for (uint16_t i = 1u; i < 10u; i++)       /* 9 条竖网格线 */
        LCD_DrawLine(x1 + i * OSC_PX_PER_DIV, y1, x1 + i * OSC_PX_PER_DIV, y2,
                     1, OSC_C_GRID);
    for (uint16_t i = 1u; i < 8u; i++)        /* 7 条横网格线 */
        LCD_DrawLine(x1, y1 + i * OSC_PX_PER_DIV, x2, y1 + i * OSC_PX_PER_DIV,
                     1, OSC_C_GRID);

    /* 中十字 + 四条边框, 亮一档 */
    LCD_DrawLine(x1, y1 + OSC_H / 2u, x2, y1 + OSC_H / 2u, 1, OSC_C_GRIDC);
    LCD_DrawLine(x1 + OSC_W / 2u, y1, x1 + OSC_W / 2u, y2, 1, OSC_C_GRIDC);
    LCD_DrawLine(x1, y1, x2, y1, 1, OSC_C_GRIDC);
    LCD_DrawLine(x1, y2, x2, y2, 1, OSC_C_GRIDC);
    LCD_DrawLine(x1, y1, x1, y2, 1, OSC_C_GRIDC);
    LCD_DrawLine(x2, y1, x2, y2, 1, OSC_C_GRIDC);
}

/* 码值(0~4095) -> 屏幕 y。信号中点自动放窗口中央, 量程决定纵向缩放 */
static int32_t code_to_y(uint16_t code, int32_t mid_mv, uint16_t vdiv_mv)
{
    int32_t mv = (int32_t)((uint32_t)code * 3300u / 4096u);
    int32_t y  = (int32_t)(OSC_Y0 + OSC_H / 2u)
               - (mv - mid_mv) * (int32_t)OSC_PX_PER_DIV / (int32_t)vdiv_mv;

    if (y < (int32_t)OSC_Y0)                    y = (int32_t)OSC_Y0;
    if (y > (int32_t)(OSC_Y0 + OSC_H - 1u))     y = (int32_t)(OSC_Y0 + OSC_H - 1u);
    return y;
}

static void draw_wave(const meas_t *m, uint16_t trig_ofs)
{
    static const uint16_t vdiv_tab[3] = { 1000u, 500u, 250u };   /* mV/格 */
    uint16_t vdiv_mv = vdiv_tab[s_vdiv];
    int32_t  mid_mv  = (int32_t)((uint32_t)(m->code_max + m->code_min)
                                 * 3300u / 8192u);   /* (max+min)/2 对应的 mV */
    int32_t  prev_y  = -1;

    for (uint16_t col = 0; col < OSC_W; col++)
    {
        uint16_t s   = (uint16_t)((uint32_t)col * trace_n / OSC_W);
        uint16_t cnt = (uint16_t)((uint32_t)(col + 1u) * trace_n / OSC_W) - s;
        uint16_t mx = 0, mn = 0xFFFF;

        for (uint16_t k = 0; k < cnt; k++)    /* 索引含触发偏移, 对 trace_n 回绕 */
        {
            uint16_t v = trace[(uint16_t)(s + k + trig_ofs) % trace_n];
            if (v > mx) mx = v;
            if (v < mn) mn = v;
        }

        int32_t y_top = code_to_y(mx, mid_mv, vdiv_mv);   /* 电压高 -> y 小 */
        int32_t y_bot = code_to_y(mn, mid_mv, vdiv_mv);

        if (y_top == y_bot)                   /* 平坦列: 与上一列连线, 防断线 */
        {
            if (prev_y < 0)
                LCD_DrawPoint(OSC_X0 + col, (uint16_t)y_top, 1, OSC_C_TRACE);
            else
                LCD_DrawLine(OSC_X0 + col - 1u, (uint16_t)prev_y,
                             OSC_X0 + col, (uint16_t)y_top, 1, OSC_C_TRACE);
            prev_y = y_top;
        }
        else                                  /* 跨度列: 画竖直包络 (真示波器画法) */
        {
            LCD_DrawLine(OSC_X0 + col, (uint16_t)y_top,
                         OSC_X0 + col, (uint16_t)y_bot, 1, OSC_C_TRACE);
            prev_y = (y_top + y_bot) / 2;
        }
    }
}

/* ---------- 停触发源 -> 顺序拷最近 n 个样本 -> 重启 ----------
   停表期间没人触发 ADC, DMA 的 CNDTR 冻结, 拷贝与写入绝不交叠 => 无撕裂 */
static void snapshot(uint16_t n)
{
    HAL_TIM_Base_Stop(&htim3);
    uint16_t head = (uint16_t)(OSC_BUF_LEN - DMA1_Channel1->CNDTR); /* DMA 写到哪 */

    for (uint16_t i = 0; i < n; i++)
    {
        uint16_t idx = (uint16_t)(head + OSC_BUF_LEN - n + i);
        if (idx >= OSC_BUF_LEN) idx -= OSC_BUF_LEN;
        trace[i] = adc_buf[idx];
    }
    HAL_TIM_Base_Start(&htim3);
}

/* ---------- 峰峰值 + 测周期算频率 + 占空比 (全程整数: mV / 0.1Hz / 0.1%) ---------- */
static void measure(meas_t *m)
{
    uint16_t vmax = 0, vmin = 0xFFFF;

    for (uint16_t i = 0; i < trace_n; i++)
    {
        if (trace[i] > vmax) vmax = trace[i];
        if (trace[i] < vmin) vmin = trace[i];
    }
    m->code_max = vmax;
    m->code_min = vmin;
    m->vpp_mv   = (uint32_t)(vmax - vmin) * 3300u / 4096u;
    m->freq_x10 = 0;
    m->duty_x10 = 0xFFFFFFFFu;

    uint16_t mid = vmin + (vmax - vmin) / 2u;
    if ((uint16_t)(vmax - vmin) < 40u) return;   /* 幅度 < 33mV 视为直流/静默 */

#define EDGE_MAX 16
    uint16_t rise[EDGE_MAX], fall[EDGE_MAX];     /* 过中点位置, 单位: 0.1 样本 */
    uint8_t  nr = 0, nf = 0;

    for (uint16_t i = 1u; i < trace_n; i++)
    {
        int32_t a = (int32_t)trace[i - 1u] - mid;
        int32_t b = (int32_t)trace[i]      - mid;

        if (a < 0 && b >= 0)                     /* 上升穿中点 */
        {
            if (nr < EDGE_MAX)
                rise[nr++] = (uint16_t)((i - 1u) * 10 + a * 10 / (a - b));
        }
        else if (a > 0 && b <= 0)                /* 下降穿中点 */
        {
            if (nf < EDGE_MAX)
                fall[nf++] = (uint16_t)((i - 1u) * 10 + a * 10 / (a - b));
        }
    }
    /* a*10/(a-b) 是线性插值: 交点不在整样本上也能算到 0.1 样本精度 */

    if (nr >= 2u)   /* 首尾沿平均: 一帧 10~100 个周期摊薄量化误差 => 误差 <0.5% */
    {
        m->freq_x10 = (uint32_t)OSC_FS * 100u * (uint32_t)(nr - 1u)
                    / (uint32_t)(rise[nr - 1u] - rise[0]);
    }

    if (nr >= 1u && nf >= 1u)   /* 占空比 = 高电平时间 / 整周期 */
    {
        uint16_t f0 = 0xFFFF, r1 = 0xFFFF;

        for (uint8_t k = 0; k < nf; k++)
            if (fall[k] > rise[0]) { f0 = fall[k]; break; }
        for (uint8_t k = 0; k < nr; k++)
            if (rise[k] > f0)      { r1 = rise[k]; break; }

        if (f0 != 0xFFFF && r1 != 0xFFFF)
            m->duty_x10 = (uint32_t)(f0 - rise[0]) * 1000u
                        / (uint32_t)(r1 - rise[0]);
    }
}

/* ---------- 软件触发: 找第一个上升穿中点的样本, 每帧同相位画 => 锁定不滚 ---------- */
static uint16_t find_trigger(const meas_t *m)
{
    if (!s_trig_en) return 0;
    if ((uint16_t)(m->code_max - m->code_min) < 40u) return 0;   /* 直流不触发 */

    uint16_t mid = m->code_min + (m->code_max - m->code_min) / 2u;
    for (uint16_t i = 1u; i < trace_n; i++)
        if (trace[i - 1u] < mid && trace[i] >= mid) return i;
    return 0;
}

/* ==================== 顶部状态栏 / 底部测量栏 ==================== */
static void draw_status(void)
{
    static const char tb_txt[2][6] = { "1ms", "10ms" };
    static const char vd_txt[3][7] = { "1V", "0.5V", "0.25V" };
    char buf[40];

    snprintf(buf, sizeof(buf), "TB:%s/div  V:%s/div  TRG:%s",
             tb_txt[s_tb], vd_txt[s_vdiv], s_trig_en ? "ON" : "OFF");
    LCD_WriteAsiciStr(0, 0, 16, WHITE, BLACK, (uint8_t *)buf);
}

static void draw_meas(const meas_t *m)
{
    char buf[48];

    if (m->freq_x10 == 0u)
    {
        snprintf(buf, sizeof(buf), "Vpp=%4lu mV  F=----.- Hz  D=--.-%%",
                 (unsigned long)m->vpp_mv);
    }
    else if (m->duty_x10 == 0xFFFFFFFFu)
    {
        snprintf(buf, sizeof(buf), "Vpp=%4lu mV  F=%lu.%lu Hz  D=--.-%%",
                 (unsigned long)m->vpp_mv,
                 (unsigned long)(m->freq_x10 / 10u),
                 (unsigned long)(m->freq_x10 % 10u));
    }
    else
    {
        snprintf(buf, sizeof(buf), "Vpp=%4lu mV  F=%lu.%lu Hz  D=%lu.%lu%%",
                 (unsigned long)m->vpp_mv,
                 (unsigned long)(m->freq_x10 / 10u),
                 (unsigned long)(m->freq_x10 % 10u),
                 (unsigned long)(m->duty_x10 / 10u),
                 (unsigned long)(m->duty_x10 % 10u));
    }
    LCD_WriteAsiciStr(0, OSC_Y0 + OSC_H + 8u, 16, WHITE, BLACK, (uint8_t *)buf);
}

/* ==================== 按键 ====================
   KEY0 = PE4  上拉输入, 按下 = 低 (GPIO_PIN_RESET)
   KEY1 = PE3  上拉输入, 按下 = 低
   KEY_UP = PA0 下拉输入, 按下 = 高  <-- 和前两个相反!
   消抖铁律: *_last 的更新必须放在"电平稳定 20ms 且与上次确认值不同"的分支里 */
static uint8_t s_key_evt = 0;   /* bit0=KEY0 bit1=KEY1 bit2=KEY_UP, 待消费 */

static void keys_init(void)
{
    GPIO_InitTypeDef g = {0};

    __HAL_RCC_GPIOE_CLK_ENABLE();
    __HAL_RCC_GPIOA_CLK_ENABLE();
    g.Mode  = GPIO_MODE_INPUT;
    g.Speed = GPIO_SPEED_FREQ_LOW;

    g.Pin  = GPIO_PIN_3 | GPIO_PIN_4;
    g.Pull = GPIO_PULLUP;
    HAL_GPIO_Init(GPIOE, &g);

    g.Pin  = GPIO_PIN_0;
    g.Pull = GPIO_PULLDOWN;
    HAL_GPIO_Init(GPIOA, &g);
}

static void keys_scan(void)
{
    static uint8_t  k0_now = GPIO_PIN_SET,   k0_last = GPIO_PIN_SET;
    static uint8_t  k1_now = GPIO_PIN_SET,   k1_last = GPIO_PIN_SET;
    static uint8_t  ku_now = GPIO_PIN_RESET, ku_last = GPIO_PIN_RESET;
    static uint32_t k0_t = 0, k1_t = 0, ku_t = 0;
    uint32_t now = HAL_GetTick();
    uint8_t  r;

    r = (uint8_t)HAL_GPIO_ReadPin(GPIOE, GPIO_PIN_4);        /* KEY0 */
    if (r != k0_now) { k0_now = r; k0_t = now; }
    else if (k0_now != k0_last && (now - k0_t) >= 20u)
    {
        k0_last = k0_now;
        if (k0_now == GPIO_PIN_RESET) s_key_evt |= 0x01u;
    }

    r = (uint8_t)HAL_GPIO_ReadPin(GPIOE, GPIO_PIN_3);        /* KEY1 */
    if (r != k1_now) { k1_now = r; k1_t = now; }
    else if (k1_now != k1_last && (now - k1_t) >= 20u)
    {
        k1_last = k1_now;
        if (k1_now == GPIO_PIN_RESET) s_key_evt |= 0x02u;
    }

    r = (uint8_t)HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0);        /* KEY_UP: 反相 */
    if (r != ku_now) { ku_now = r; ku_t = now; }
    else if (ku_now != ku_last && (now - ku_t) >= 20u)
    {
        ku_last = ku_now;
        if (ku_now == GPIO_PIN_SET) s_key_evt |= 0x04u;
    }
}

/* ==================== 对外接口 ==================== */
void OSC_Init(void)
{
    keys_init();
    HAL_ADCEx_Calibration_Start(&hadc1);            /* F1 上电必做: 修电容组误差 */
    HAL_ADC_Start_DMA(&hadc1, (uint32_t *)adc_buf, OSC_BUF_LEN);
    HAL_TIM_Base_Start(&htim3);                     /* TRGO 每 50us 打一枪 */
}

void OSC_UIInit(void)
{
    fill_rect(OSC_X0, OSC_Y0, OSC_W, OSC_H, OSC_C_BG);
    draw_grid();
    draw_status();
    LCD_WriteAsiciStr(0, OSC_Y0 + OSC_H + 8u, 16, WHITE, BLACK,
                      (uint8_t *)"Vpp=---- mV  F=----.- Hz  D=--.- %");
}

void OSC_Task(void)
{
    keys_scan();

    if (s_key_evt & 0x01u)   /* KEY0: 时基 1ms <-> 10ms */
    {
        s_key_evt &= ~0x01u;
        s_tb = (s_tb == OSC_TB_1MS) ? OSC_TB_10MS : OSC_TB_1MS;
    }
    if (s_key_evt & 0x02u)   /* KEY1: 量程 1V -> 0.5V -> 0.25V 循环 */
    {
        s_key_evt &= ~0x02u;
        s_vdiv = (osc_vdiv_t)(((uint8_t)s_vdiv + 1u) % 3u);
    }
    if (s_key_evt & 0x04u)   /* KEY_UP: 触发开关 (演示"没有触发会怎样") */
    {
        s_key_evt &= ~0x04u;
        s_trig_en ^= 1u;
    }

    if (HAL_GetTick() - s_last_ms < FRAME_MS) return;
    s_last_ms = HAL_GetTick();

    trace_n = (s_tb == OSC_TB_1MS) ? 200u : 2000u;
    snapshot(trace_n);

    meas_t m;
    measure(&m);
    uint16_t trig_ofs = find_trigger(&m);

    fill_rect(OSC_X0, OSC_Y0, OSC_W, OSC_H, OSC_C_BG);   /* 擦波形区 */
    draw_grid();                                          /* 重铺网格 */
    draw_wave(&m, trig_ofs);
    draw_status();
    draw_meas(&m);
}

/* ==================== 可选: 板载自测信号 ====================
   PA8 = TIM1_CH1 输出 1kHz / 50% 方波, 杜邦线 PA8->PC0 即可完成方波验收。
   注意: 若已在 CubeMX 配了 TIM1, 删掉本函数, 二选一, 别两边同时配 */
static TIM_HandleTypeDef s_htim1;

void OSC_TestSignal_Start(void)
{
    GPIO_InitTypeDef   g  = {0};
    TIM_OC_InitTypeDef oc = {0};

    __HAL_RCC_TIM1_CLK_ENABLE();
    __HAL_RCC_GPIOA_CLK_ENABLE();
    g.Pin   = GPIO_PIN_8;
    g.Mode  = GPIO_MODE_AF_PP;
    g.Speed = GPIO_SPEED_FREQ_HIGH;
    HAL_GPIO_Init(GPIOA, &g);

    s_htim1.Instance               = TIM1;
    s_htim1.Init.Prescaler         = 72u - 1u;    /* 72MHz/72 = 1MHz 计数 */
    s_htim1.Init.CounterMode       = TIM_COUNTERMODE_UP;
    s_htim1.Init.Period            = 1000u - 1u;  /* 1MHz/1000 = 1kHz */
    s_htim1.Init.ClockDivision     = TIM_CLOCKDIVISION_DIV1;
    s_htim1.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_ENABLE;
    HAL_TIM_PWM_Init(&s_htim1);

    oc.OCMode     = TIM_OCMODE_PWM1;
    oc.Pulse      = 500u;                          /* 50% */
    oc.OCPolarity = TIM_OCPOLARITY_HIGH;
    HAL_TIM_PWM_ConfigChannel(&s_htim1, &oc, TIM_CHANNEL_1);

    HAL_TIM_PWM_Start(&s_htim1, TIM_CHANNEL_1);   /* 高级定时器: 内部自动置 MOE */
}

七、测试步骤 (对着验收标准来)
--------------------------------------------------------------------------------
1. 编译烧录, 不接任何信号 (PC0 悬空):
   波形 = 一条水平线, Vpp ≈ 0, F=----, D=--.-  => ADC+DMA+LCD 链路通
   (开机头 0.1s 可能闪一下异常帧: 环形缓冲里还有全 0, 属正常)
2. 杜邦线 PA8 -> PC0:
   显示 1kHz 方波, Vpp ≈ 3300mV, F ≈ 1000.0Hz, D ≈ 50.0%  => 方波验收通过
   KEY0 切 10ms/格: 变成 100 个周期密成一片 (正常现象, 触发后仍然稳定)
   KEY1 切量程: 波形纵向放大/缩小, 测量数值不变 (软件换算)
   KEY_UP 关触发: 波形左右漂移; 再按打开: 立刻锁住 => 触发加分项现场演示
3. 信号发生器正弦: 1kHz、偏置 1.65V、幅度 1Vpp
   Vpp 读数 vs 发生器标称 (差 ±50mV 内正常: 3.3V 基准 ±1% + 量化)
   频率误差: 显示值 vs 发生器标称, 应 < 2% (这套算法实际 < 0.5%)
4. 频率精度抽查: 换 500Hz / 2kHz 各再测一次


八、坑 (踩过一遍就不用再踩)
--------------------------------------------------------------------------------
1. 时钟必须 72MHz。42 工程现在是 8MHz 降速实验状态, 直接抄它的时钟配置,
   采样率会变成 2.2kHz, LCD 刷新慢 9 倍, 全盘不对。
2. Continuous Conversion Mode 必须关。开着 = ADC 自由运行, 触发源被无视,
   采样率不受控 —— 题目明令禁止的就是这个。
3. 快照防撕裂: 停 TIM3 -> 拷贝 -> 重启 TIM3。不停表直接读环形缓冲,
   会拷到"一半新一半旧"的接缝, 波形上多一根莫名其妙的竖线。
4. 触发不是加分项, 是必需品。没触发时 20FPS 自由刷新, 1kHz 方波必然
   左右乱跑, "稳定不滚动"这条验收过不了。
5. 全程整数运算 (mV / 0.1Hz / 0.1%)。别上 float + printf %f,
   MicroLIB/浮点库是多余的坑, 示波器根本不需要浮点。
6. 频率精度靠"首尾沿平均": 一帧 10~100 个周期取平均, 单次 ±1 样本的
   量化误差被摊薄到 0.1%~0.5%。只测单周期会顶到 5% 误差, 过不了验收。
7. ADC 时钟 <= 14MHz (这里 /6 = 12MHz), 采样时间选 28.5 周期;
   太短会因采样电容充不满导致读数偏低、毛刺多。
8. 别忘了 HAL_ADCEx_Calibration_Start()。F1 的 ADC 上电必须校准,
   否则读数整体偏几十个码。
9. 1ms/格 下 1kHz 有 10 个周期; 想看单周期细节可自己加 100us/格 档
   (TIM3 的 ARR 改 359 => 200kHz, 一屏 20 个样本, 快照仍取 200 用于测量)。
10. 输入信号只能 0~3.3V。±5V 双极性信号直接进 = 换芯片。


九、加分项扩展思路 (先过验收再说)
--------------------------------------------------------------------------------
- 触发: 基础版已实现 (上升沿 + 自动中点电平), 这就是"示波器的灵魂"。
  进阶: 触发电平改为可用按键调, 加"未触发就不刷新"策略 (Auto/Normal 模式)。
- 多通道: ADC1 开 Scan + 2 通道 (如 IN10=PC0 + IN13=PC3), NbrOfConversion=2,
  DMA 缓冲变成 CH0,CH1,CH0,CH1 交织, 按奇偶拆开画两条迹线 (不同颜色),
  注意等效采样率减半。
- 自动档位 Auto: 每帧看 Vpp 占的格数, < 2 格升量程、> 7 格降量程,
  加 ±1 格迟滞, 防止在临界档位来回抖。
- 刷新优化: 现在每帧全区域重画, 若觉得有轻微闪烁, 可改成"只擦上一帧
  迹线所在列再画新迹线" (需要保存上一帧每列的 y 范围)。
